# rollnw 2026.10.24

This snapshot releases **rollnw-client 0.3.0**. Other bundled tools retain
development versions and are not approved as stable releases in this snapshot.

Watch the [Item Interactions demo](https://youtu.be/EhH9qhWr8ok).

Release preparation requires a complete test-suite run with the renderer
enabled and another with it disabled, followed by passing CI for the release
commit. Focused test runs and graphics smoke checks alone do not qualify.

- Play preview supports queued movement, animated item pickup, timed weapon
  equipment changes, and item dropping. Leaving preview restores the authored
  area instead of saving its temporary gameplay changes.
- Press **I** or run **object.inventory.open** to open a movable, translucent
  inventory window. Drag items between the pack and equipment slots, place them
  in specific cells, and inspect names on hover. Drop outlines show whether a
  destination is valid. Creature workbench inventories also support drag and drop.
- Weapon equip and unequip animations preserve the underlying idle or locomotion
  channels. Equipment visual replacement keeps the base animation clock running.
- Item editing includes appearance controls and isolated model previews; creature
  class editing and encounter spawn editing have dedicated controls. Equipment
  swaps and editor inventory removal support undo.
- Renderer changes retain unchanged animation poses, share repeated glTF geometry,
  reuse packed material textures, and harden upload and submission lifetimes.
- Headless tests no longer pull SDL headers through the client input interface.

## Source compatibility

C++ consumers should rebuild against this revision. Animation backend sampling
now accepts an optional sample mode; custom implementations of the backend
interface must update their override. Overlay sampling requires a base pose with
the matching joint count and preserves channels absent from the overlay clip.
No persisted project-format migration is required by these changes.

Linux x64 and Windows x64 packages contain the client, mudl, and the three Smalls
tools. The macOS universal package contains the three Smalls tools; the client is
available on Linux and Windows. Keep executables with their packaged assets and
script libraries. VS Code extension packaging remains separate.

For headless software rendering, the graphics smoke scenes pass with Ubuntu
24.04's Mesa 25.2.8 / LLVM 20.1.2. Ubuntu 22.04's Mesa 23.2.1 / LLVM 15.0.7
stalls in first-frame shader optimization in the dragon scene; use the newer
software driver for these runs. Linux packages retain their Ubuntu 22.04 build
baseline.
