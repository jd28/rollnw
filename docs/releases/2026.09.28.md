# rollnw 2026.09.28

This patch snapshot releases all five tools:

| Tool | Version |
| --- | --- |
| rollnw-client | 0.2.1 |
| mudl | 0.5.1 |
| smalls | 0.1.1 |
| smalls-lsp | 0.1.1 |
| smalls-datagen | 0.1.1 |

- Windows executables and DLLs are signed and timestamped with Azure Artifact
  Signing. CI verifies their signatures before publishing the package.
- The client scales its interface and input coordinates to display density,
  addressing undersized controls on Windows and X11.
- Area-list thumbnails load correctly from Windows file URLs.
- Linux packages require SDL Wayland support, enabling native Wayland sessions.
- The project tree hides Git metadata and the root `.rollnw` directory on all
  platforms, and honors project-local `.gitignore` rules, including nested files.

Linux x64 and Windows x64 packages contain all five tools. The macOS universal
package contains the three Smalls tools. Keep executables with their packaged
assets and script libraries. VS Code extension packaging and Marketplace
publication remain separate from this distribution.
