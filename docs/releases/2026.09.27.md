# rollnw 2026.09.27

This snapshot releases all five command-line and desktop tools:

| Tool | Version |
| --- | --- |
| rollnw-client | 0.2.0 |
| mudl | 0.5.0 |
| smalls | 0.1.0 |
| smalls-lsp | 0.1.0 |
| smalls-datagen | 0.1.0 |

## Highlights

- The toolset supports native area creation and deletion, terrain and tile
  editing, object placement, blueprint creation, and blueprint reference updates.
  Encounter spawn entries and Sound resource entries support removal and undo.
- Save, close, and error prompts use application dialogs that block editor input.
  Failed saves retain unsaved documents for retry, and repeated window-close
  requests leave the pending prompt intact. File and folder pickers remain native.
- The Smalls language server fixes a crash when opening or editing preludes and
  refreshes diagnostics in dependent documents. Bundled host API declarations
  resolve without requiring the application host.
- Shared area rendering restores cascade shadows. The toolset loads its bundled
  script packages consistently across launch directories and project reloads.

## Downloads and compatibility

Linux x64 and Windows x64 packages contain all five tools. The macOS universal
package contains `smalls`, `smalls-lsp`, and `smalls-datagen`.
Keep each executable with its packaged assets and script libraries. NWN content
workflows require an NWN:EE installation and the module's required hak files.

These are 0.x tool releases. The toolset does not yet cover every NWToolset
workflow; its editable project format uses native CAF areas and JSON resources.
See the [toolset guide](../../tools/client/README.md) for supported workflows and
limitations. C++ consumers must rebuild the library and their applications
together; cross-revision ABI compatibility is not guaranteed.

VS Code extension packaging and Marketplace publication are separate from this
distribution.
