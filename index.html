rollnw

rollnw is a C++ framework for RPG tools and runtimes, inspired by Neverwinter Nights and growing toward a modern authored game and toolset.

  • nw — library for content formats, resources, rules, and a Vulkan renderer with PBR materials, animation, particles, lighting, and shadows.
  • smalls — a statically typed scripting language for game rules and tooling, with a VS Code extension.
  • client — Demo — import modules, explore areas, and edit objects and terrain with previews, undo, and save.
  • mudl — inspect models and effects, capture screenshots, and benchmark rendering with NWN and glTF assets.

The project is in active development. Pin a Git revision and rebuild consumers when updating; APIs and the C++ ABI can change. See the release guide for snapshot and tool versioning.

Build

Requires CMake 3.21+ and a C++20 compiler. Renderer tools currently only run on Linux and Windows. For a Linux renderer build with Ninja:

cmake --preset linux-renderer-dev
cmake --build --preset linux-renderer-dev --target rollnw-client mudl
./build-renderer/tools/client/rollnw-client

Use windows-renderer-dev for Windows. Library development presets are linux-dev, macos-dev, and windows-dev; see CMakePresets.json for the available configurations.

To work with NWN content, install NWN:EE and any required hak files. If discovery fails, set NWN_ROOT to the game installation and NWN_HOME to its user directory. In the toolset, choose Import Module... on Home. See the toolset guide for the workflow.
